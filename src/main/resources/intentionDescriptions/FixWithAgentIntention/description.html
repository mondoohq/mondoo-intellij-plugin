Fixes an xgrep finding through xgrep fix serve and opens the Fix tab.

A deterministic fix is applied by xgrep; an agent-assisted one is handed to your coding agent (Claude Code, Codex, or the command set in Settings | Tools | Mondoo). Either way xgrep re-scans and reports the fix as applied only if the finding is gone. The agent's output streams to the xgrep fix console, and a Local History label lets you undo the whole run.
