# CLAUDE.md

## This repository is public

Never reference private repositories here. That covers their names and URLs, issue and
pull request numbers (`owner/repo#123`), ADRs and design documents, file paths, branch
names and internal links. It applies everywhere this repository publishes text:

- code, comments, tests and docs (including `docs/adr/`);
- commit messages;
- pull request titles, descriptions, comments and review replies.

Describe what is needed instead, in terms a public reader can check: "requires xgrep
0.58.0 or newer with `xgrep fix serve`", not a link to the change that added it. Before
pushing or editing a pull request, search the diff, the commit messages and the
description for references to private repositories.
